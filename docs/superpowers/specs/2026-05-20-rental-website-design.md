# 房屋租赁网站设计方案

**日期：** 2026-05-20  
**项目：** 个人房屋出租与求租平台  
**目标用户：** 20-30岁年轻人群

---

## 1. 项目概述

### 1.1 项目目标
打造一套面向个人用户的房屋租赁平台，让用户可以：
- 浏览和搜索房源
- 发布出租房源
- 发布求租需求
- 管理个人发布的信息

### 1.2 设计理念
**活力渐变风格** - 采用大胆的渐变色搭配流畅的动画，打造年轻人喜欢的现代感界面，让租房这件事变得有趣、高效、有吸引力。

## 2. 视觉设计

### 2.1 配色方案

| 颜色类型 | 颜色值 | 用途 |
|---------|--------|------|
| 主渐变1 | #667eea → #764ba2 | 按钮、Header、强调元素 |
| 主渐变2 | #f093fb → #f5576c | 点缀色、CTA按钮 |
| 背景色 | #f8fafc | 页面背景 |
| 卡片背景 | #ffffff | 内容卡片 |
| 主文字 | #2d3748 | 标题、重要文字 |
| 次要文字 | #4a5568 | 正文、描述文字 |
| 辅助文字 | #718096 | 辅助信息 |

### 2.2 字体方案

| 用途 | 字体 | 字重 |
|------|------|------|
| 大标题 | Poppins | 700 |
| 小标题 | Poppins | 600 |
| 正文 | Inter | 400 |
| 强调文字 | Inter | 500 |

### 2.3 动效设计

- **卡片悬停：** 上浮 8px + 阴影增强
- **按钮：** 点击缩放 0.95 + 渐变流动
- **页面加载：** 元素错峰入场（staggered reveal）
- **图片轮播：** 平滑滑动过渡
- **表单交互：** 输入框聚焦时边框高亮

## 4. 功能设计

### 4.1 核心功能

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 房源搜索 | 按位置、价格、房型筛选 | JS 过滤 + localStorage |
| 房源收藏 | 收藏感兴趣的房源 | localStorage |
| 图片轮播 | 房源详情页图片展示 | CSS/JS 实现 |
| 房源管理 | 编辑、删除、标记已租 | localStorage CRUD |
| 发布房源 | 分步式表单 | 多步表单 + 本地存储 |
| 求租发布 | 发布求租需求 | 表单 + 本地存储 |
| 响应式布局 | 适配手机、平板、桌面 | CSS Grid + Flexbox |

### 4.2 数据结构

**房源数据 (Property):**
```javascript
{
  id: string,
  title: string,
  location: string,
  price: number,
  rooms: number,
  area: number,
  images: string[],
  description: string,
  facilities: string[],
  contact: {
    name: string,
    phone: string
  },
  status: 'available' | 'rented',
  createdAt: Date,
  userId: string
}
```

**求租数据 (Request):**
```javascript
{
  id: string,
  budget: { min: number, max: number },
  location: string,
  rooms: number,
  preferences: string[],
  description: string,
  contact: {
    name: string,
    phone: string
  },
  createdAt: Date,
  userId: string
}
```

**用户数据 (User):**
```javascript
{
  id: string,
  name: string,
  avatar: string,
  phone: string,
  favorites: string[]
}
```

## 5. 技术实现

### 5.1 技术栈

- **HTML5** - 语义化标签
- **CSS3** - Grid/Flexbox、动画、渐变
- **Vanilla JavaScript** - 无框架
- **localStorage** - 数据持久化

```

├── css/
```
